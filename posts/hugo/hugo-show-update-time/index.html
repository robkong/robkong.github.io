开启 Hugo 的 GitInfo 功能
#

默认情况下，Hugo 不会读取 .git 目录。需要修改配置文件 hugo.toml

1# 在配置文件中添加这一行
2enableGitInfo = true

开启后，Hugo 会自动从 Git 历史中提取每篇文章的最后提交时间。

调整 GitHub Actions 工作流
#

GitHub Actions 默认使用 fetch-depth: 1（浅克隆），只下载最新的快照，不包含历史记录，这会导致 Hugo 拿不到正确的 Git 修改时间。

需要修改 .github/workflows/hugo.yml 文件：

1      - name: Checkout
2        uses: actions/checkout@v6
3        with:
4          submodules: true
5          fetch-depth: 0 # 必须设置为 0，获取所有历史记录，否则获取不到正确的 Git 修改时间
6
7      # 时区校准，GitHub Actions 的运行环境默认是 UTC 时间，可能导致提交时间比北京时间晚 8 小时
8      - name: Set timezone
9        run: sudo timedatectl set-timezone 'Asia/Shanghai'
