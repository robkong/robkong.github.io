概述
#

Hugo 是一款用 Go 语言开发的静态网站生成器，可在几秒钟内渲染一个完整的网站。

安装必要工具
#

安装 Hugo
#

用途：用于开发静态网站项目，推荐安装 hugo-extended 版本

安装：

  1. 访问 GitHub Releases

  2. 下载合适的版本

    hugo_extended_withdeploy_0.155.3_windows-amd64.zip

  3. 解压到指定目录

    D:\Environment\Hugo\hugo_extended

    注意：解压后的文件名可重命名

  4. 添加到环境变量

    此电脑右击 ——> 属性 ——> 高级系统设置 ——> 环境变量（系统变量） ——> 双击 Path 目录 ——> 点击新建 D:\Environment\Hugo\hugo_extended ——> 确定

  5. 验证安装

    Win + R 输入 cmd 回车

    1# 查看版本
2hugo version
3
4# 输出结果，证明安装成功
5hugo v0.155.3-8a858213b73907e823e2be2b5640a0ce4c04d295+extended+withdeploy windows/amd64 BuildDate=2026-02-08T16:40:42Z VendorInfo=gohugoio

安装 Git
#

用途：Hugo 项目通常需要 Git 进行版本控制和主题管理

安装：

  1. 访问 Git 官网

  2. 点击 Install for Windows ——> Click here to download

  3. 双击 Git-2.53.0-64-bit.exe 进行安装（安装步骤自行搜索）

  4. 验证安装

    1   # 查看版本
2   git --version
3
4   # 输出结果，证明安装成功
5   git version 2.53.0.windows.1

  5. 首次配置

桌面右击 ——> Open Git Bash here

1git config --global user.name "Sizeskong"
2git config --global user.email "sizeskong@gmail.com"

安装 Dart Sass
#

用途：将 Sass 转换为 CSS

安装：

  1. 访问 GitHub Releases

  2. 下载合适的版本

    dart-sass-1.97.3-windows-x64.zip

  3. 解压到指定目录

    D:\Environment\Hugo\dart-sass

    注意：解压后的文件名可重命名

  4. 添加到环境变量

    此电脑右击 ——> 属性 ——> 高级系统设置 ——> 环境变量（系统变量） ——> 双击 Path 目录 ——> 点击新建 D:\Environment\Hugo\dart-sass ——> 确定

  5. 验证安装

    1# 查看版本
2sass --version
3
4# 输出结果，证明安装成功
51.97.3

生成项目骨架

 1kongBlog/
 2├── archetypes/       # 内容模板
 3├── assets/           # 静态资源（CSS、JS等）
 4├── content/          # 内容源文件
 5├── data/             # 数据文件
 6├── i18n/             # 国际化文件
 7├── layouts/          # 自定义布局
 8├── static/           # 静态文件（图片等）
 9├── themes/           # 主题目录
10└── hugo.yaml         # 配置文件

添加主题皮肤
#

使用 Git 子模块，将 Blowfish 主题下载到 themes\ 目录下

1git submodule add -b main https://github.com/nunocoracao/blowfish.git themes/blowfish

配置站点文件
#

从主题中复制 config 文件，粘贴到网站根目录中。

粘贴后的 config 目录如下：

1config/_default/
2├─ hugo.toml			# 主配置文件
3├─ languages.en.toml 	# 语言和作者信息
4├─ markup.toml			# 内容标记配置
5├─ menus.en.toml 		# 导航菜单配置
6├─ module.toml  		# 通过 Hugo 模块安装，不用理会
7└─ params.toml			# 主题参数配置
重要

尽管 Blowfish 主题支持多语言，但是 hugo.toml 只能配置一个主语言。

设置中文为主语言

把languages.en.toml 重命名为 languages.zh-cn.toml

把menus.en.toml 重命名为 menus.zh-cn.toml

打开 hugo.toml 文件中，设置 defaultContentLanguage = "zh-cn"

启动本地服务
#

1# 启动服务（包含草稿内容）
2hugo server -D
3
4# 启动服务（不包含草稿内容）
5hugo server

-D 标志表示构建草稿内容。服务器会：

  • 在本地构建网站并提供服务（通常在 http://localhost:1313）
  • 监控项目目录中的文件变化
  • 检测到变化时自动重建并实时刷新浏览器（LiveReload）

预览网站页面
#

在浏览器中访问 http://localhost:1313

尝试修改内容文件或配置，保存后浏览器会自动刷新，显示最新更改。

编辑发布状态
#

  • draft = true 为草稿状态（默认）
  • draft = false 为发布状态

将草稿状态设置为 false：

1+++
2date = '2026-03-02T12:05:29+08:00'
3draft = false
4title = '2026.01.29'
5+++

#

1hugo

这会在项目根目录下的 public 目录中生成完整的静态网站，包括：

  • HTML 文件
  • CSS 和 JavaScript 文件
  • 图像等静态资源

常见问题
#

  1. 页面不显示： 检查 draft 状态是否设置为 false
  2. 样式不正确：确认主题配置是否正确
  3. 构建失败 ：检查 Hugo 版本和主题兼容性
