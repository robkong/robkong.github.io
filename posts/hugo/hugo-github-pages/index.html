前言
#

使用 Hugo + Blowfish 已经搭建好博客项目了，目前只能在本地访问。

为了让其它人也能访问，先使用 Github 来存储并发布网页。

准备工作
#

首先访问【 Github 官网 】，登录或注册一个 GitHub 账户。

需要创建两个仓库：

  1. 一个公有仓库，用于访问页面（存放 public 下的文件）
  2. 一个私有仓库，存放网站的源代码

这样做的好处是其他人只能看到你的页面文件，无法看到你的真实内容文件。

创建 GitHub 仓库
#

  • 创建公有仓库，仓库名称：[github用户名].github.io

  • 创建私有仓库，仓库名称自定义，最好与本地仓库一致（例如：kong-blog） 注意：设置成私有（Private）

创建令牌
#

由于 GITHUB_TOKEN 是由 GitHub 自动生成的临时令牌，它出于安全考虑被限制在当前仓库。

要推送到外部/其他仓库，必须使用个人的 Personal Access Token (PAT)。

生成 PAT
#

  1. 点击 Github 用户头像

  2. 选择 Settings

  3. 左侧找到 Developer settings

  4. 选择 Personal access tokens 下的 Tokens (classic)

  5. 点击 Generate new token 选择 Generate new token (classic)

  6. 输入账号密码

  7. Note下输入令牌备注（例如：HUGO_TOKEN）

  8. Expiration 选择 no expiration （不过期）

  9. 勾选 repo 和 workflow

  10. 点击 Generate token （生成令牌）

  11. 复制 ghp_xxx 令牌内容（只显示一次）

  12. 把令牌复制到剪切板

将 PAT 添加到仓库的 Secrets
#

  1. 进入私有仓库项目，选择 Settings
  2. 左侧找到 Secrets and variables
  3. 选择 Actions
  4. 点击 New repository secret
  5. 名称填为 GH_PAT，值贴入刚才生成的 PAT。

自动化部署
#

目的：将本地内容推送到私有仓库，自动部署页面到公有仓库。

在网站根目录创建 .github/workflows/hugo.yml

 1# 构建并部署 Hugo 网站至 GitHub Pages 的示例工作流
 2name: Deploy Hugo site to Pages
 3
 4on:
 5  push:
 6    branches:
 7      - main
 8  workflow_dispatch:
 9
10jobs:
11  build-deploy:
12    runs-on: ubuntu-latest
13    permissions:
14      contents: write  # 赋予写入权限
15    steps:
16      - name: Checkout
17        uses: actions/checkout@v6
18        with:
19          submodules: true
20          fetch-depth: 0
21
22      - name: Setup Hugo
23        uses: peaceiris/actions-hugo@v3
24        with:
25          hugo-version: "0.157.0"
26          extended: true
27
28      - name: Build
29        run: hugo --minify
30
31      - name: Deploy
32        uses: peaceiris/actions-gh-pages@v3
33        with:
34          # 设置的秘钥
35          personal_token: ${{ secrets.GH_PAT }}
36          # 指定公开仓库的名称
37          external_repository: robkong/robkong.github.io
38          # 发布分支和目录
39          publish_branch: main
40          publish_dir: ./public
笔记

此后，只要 git push 到 main 分支，GitHub 会自动构建并部署博客！

创建 .gitignore 文件
#

在项目根目录创建.gitignore文件，来避免提交不必要的文件。

1# 自动生成的文件
2public
3resources
4.hugo_build.lock

提交部署
#

将公有仓库和本地仓库关联起来，我的公有仓库名称就是本地仓库的名称

1# 生成网站
2hugo --minify
3
4# 推送到远程私有仓库
5git add .
6git commit -m "Deploy site"
7git branch -M main
8git remote add origin git@github.com:robkong/kong-blog.git
9git push -u origin main

最后，即可访问网站：https://robkong.github.io
